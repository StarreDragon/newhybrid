Dragonforge Hybrid Studio upgrade

Deploy this folder as a static site on Vercel, with index.html at the root. Existing Hoard saves in the same browser remain under the same storage key.

Hybrid Studio: selectable secondary ancestry, inherited color, visual scale patterns, and ancestry strength. The original lineart remains unchanged; this does not yet provide independently illustrated horns, wings, or tail swaps. SharpWing cannot hybridize; BeetleWing cannot hybridize with HiveWing or SilkWing.

The standalone HTML includes embedded assets and can be opened offline.
